# 🏥 Hospital & Clinic Management System

A full-stack web application designed to streamline hospital operations, manage patient records, track doctors and specializations, schedule appointments, and generate billing invoices efficiently.

---

## 🛠️ Tech Stack

### **Frontend**
* **HTML5 & CSS3**: Modern, responsive user interface design.
* **JavaScript (ES6+)**: Dynamic client-side logic and asynchronous API handling (Fetch API).
* **React / Babel (CDN)**: Declarative UI components and state rendering.

### **Backend**
* **Node.js**: JavaScript runtime environment for backend logic.
* **Express.js**: Lightweight framework for building RESTful APIs.
* **MongoDB**: NoSQL database for flexible data storage.
* **Mongoose**: ODM (Object Data Modeling) library for MongoDB and schema validation.

---

## ✨ Key Features

* 👤 **Patient Management**: Complete CRUD operations for registering, updating, and viewing patient records.
* 👨‍⚕️ **Doctor & Specialization Tracking**: Directory to view available doctors, their qualifications, and medical specialties.
* 📅 **Appointment Scheduling**: Streamlined booking system connecting patients with doctors based on availability.
* 💳 **Billing & Invoicing**: Automated billing module to calculate service charges and generate payment invoices.
* ⚡ **RESTful API Architecture**: Clean separation between client and server layers with structured endpoints.
